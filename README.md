# Vexo Digital — Fresh website package

This package is designed to upload directly to the root of a GitHub Pages repository.

## Contents
- `index.html`: complete responsive Vexo Digital agency website, including the provided public email and phone number.
- `firestone-demo/index.html`: self-contained interactive fictional pizza website portfolio demo. No external files, payment service, or separate GitHub repository are required.

## Publish
1. Create a **public** GitHub repository named `vexo-digital-new` (or any name you prefer).
2. Extract the ZIP, keeping the `firestone-demo` folder intact.
3. Upload `index.html`, `README.md`, and the entire `firestone-demo` folder **to the repository root**. On GitHub, dragging the folder from your file explorer into the upload area should preserve the directory structure. If not, use GitHub's web editor to create `firestone-demo/index.html` and paste its contents, or use Git locally.
4. Commit the changes.
5. In Settings > Pages choose Deploy from a branch, `main`, `/ (root)` and Save.
6. Visit `https://YOUR-USERNAME.github.io/REPO-NAME/` and click the Firestone Pizza demo link.
